# 토스페이먼츠 결제 웹훅 설정

토스페이먼츠 개발자센터에서 사용하는 상점의 웹훅 URL을 다음과 같이 등록합니다.

```text
https://<백엔드-도메인>/api/billing/webhooks/toss
```

등록 이벤트는 `PAYMENT_STATUS_CHANGED`입니다. Preview와 Production은 각각의 백엔드와 DB를 가리키는 별도 URL로 등록합니다.

일반결제 웹훅에는 검증용 서명이 없으므로 서버는 다음 순서로 처리합니다.

1. `tosspayments-webhook-transmission-id`를 중복 방지 키로 저장합니다.
2. 웹훅 본문에는 결제 처리에 필요한 식별 정보만 보관합니다.
3. 서버 시크릿 키로 토스의 주문번호 결제 조회 API를 호출합니다.
4. 토스 조회 결과의 주문번호, 상태, 결제금액을 내부 주문과 대조합니다.
5. 검증된 `DONE` 주문만 결제 완료 및 이용권 활성화 상태로 복구합니다.

로컬호스트 주소는 토스 서버에서 접근할 수 없으므로 개발자센터에는 공개 HTTPS 주소만 등록해야 합니다.
