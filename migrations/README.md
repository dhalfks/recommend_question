# 데이터베이스 마이그레이션

## 교수자 소유권

`20260806_professor_ownership.sql`은 다음 변경을 적용합니다.

- 학생의 소속, 연도, 과정명, 담당 교수자
- 문제와 업로드 파일의 소유 교수자
- 기존 학생·문제·파일을 교수자 `users.id=3`에 귀속
- 외래키, 역할 검증 트리거, 조회 인덱스

운영 적용 전 `users.id=3`이 기존 데이터를 소유할 교수자 계정인지 반드시 확인합니다.

적용 순서:

1. Neon 운영 브랜치에서 새 테스트 브랜치를 생성합니다.
2. 테스트 브랜치에 마이그레이션을 적용합니다.
3. 백엔드와 프런트를 테스트 브랜치에 연결해 권한 격리를 검증합니다.
4. 운영 DB에 마이그레이션을 먼저 적용합니다.
5. 마이그레이션이 성공한 다음 새 애플리케이션 코드를 배포합니다.

새 코드가 먼저 배포되면 아직 존재하지 않는 컬럼을 조회해 API가 실패합니다.

롤백 파일은 새 컬럼과 제약조건을 제거하므로 운영 데이터가 기록된 이후에는 그대로 실행하지 않습니다. 필요한 데이터를 먼저 백업하거나 역마이그레이션해야 합니다.
